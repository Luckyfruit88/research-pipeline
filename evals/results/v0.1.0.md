# Version 0.1.0 evaluation record

Date: 2026-09-09.

## Scope

Three fresh-context Codex subagents received the skill, one fabricated case and only the relevant references. The task-performing agents were not given the rubric, expected decisions or earlier case outputs. They inherited the parent runtime/model settings; a separately pinned provider revision was not recorded. No real cluster, research dataset, paid run or external communication was used.

The parent inspected the produced contracts, protocols and receipts against the raw inputs. The interrupted-run program was also rerun by the parent and its result matched byte-for-byte.

The reconstruction program returned exit code 0 for successful auditing, while its workload-complete field remained false. Process success was not reported as completion of the seven-task workload.

## Installer and package verification

- Twenty-three unit tests passed using temporary directories, including existing-content preservation, idempotence, backups, dry-run, symlink boundaries, overlapping destinations, case/hardlink aliases and interrupted promotion.
- Independent code review found two installer defects: an interrupt could leave the prior installation only in its backup, and an AGENTS destination inside the installation could alter runtime files. A follow-up reproduction showed that macOS case aliases bypassed lexical overlap checks. The guards now use filesystem identity and conservative normalized path matching; the demonstrated cases are covered by regression tests.
- The bundled skill-creator validator accepted the entrypoint. The local validator's PyYAML dependency was reused from an existing cache; the skill runtime and installer require no third-party Python package.
- The repository package check verifies required files, activation metadata and internal links. GitHub CI repeats package and installer checks; it does not rerun the model behavior evaluations.

Case-input and runtime fingerprints are in [verification.json](verification.json). Full local task traces contain machine-specific execution paths and are not distributed in this public package; the observations here summarize the actual artifact review.

## Limits

This is a small regression-oriented evaluation, not a scientific-validity benchmark or a controlled comparison against a no-skill baseline. Independent contexts using inherited model settings are not independent scientific evidence. No guarantee is made about other models, production workloads, actual biological conclusions or every future implicit activation.

The skill's engineering-control framing is qualitative. Deterministic enforcement belongs in the project's validators, execution environment and release process.
