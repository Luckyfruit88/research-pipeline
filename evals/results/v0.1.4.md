# Version 0.1.4 evaluation record

This update adds bounded discovery of published research and GitHub implementations to new study designs and substantial method choices. The design reference loads the detailed discovery guide only when it is relevant. English and Chinese documentation describe the same scope.

## Maintainer scenario review

The maintainer reviewed the fictional [paper-code-selection case](../cases/paper-code-selection/TASK.md) against the new guidance and rubric. This was a manual assessment, not an independent or blind agent run.

- Cedar is the provisional starting point because the supplied methods and author-linked implementation fit feature-matrix inputs and disjoint-entity evaluation. Archival status and an older environment warrant a compatibility check; they do not invalidate the method. No installation or successful execution is claimed.
- Aurora remains unsuitable as the ready implementation: the inspected community code requires unavailable raw waveforms, and its row-random split differs from the target question. The abstract-only metric cannot be ranked against Cedar's held-out-entity metric. The paper-to-code relationship, full methods and license remain limited or unknown as stated in the source cards.
- If Cedar becomes unavailable, the missing evidence is retained. The source bundle does not justify promoting Aurora, claiming novelty or asserting that no other code exists. A next step would resolve the method/input gaps or locate another implementation within an authorized retrieval scope.
- The bounded follow-up explains the supplied grouped split directly, reusing unchanged evidence without a new search or study scaffold.

## Separate live retrieval probe

On 2026-10-27, a read-only source probe retrieved the [published minimap2 record](https://pubmed.ncbi.nlm.nih.gov/29750242/). Its availability statement directly links the implementation repository. The PMC full-text endpoint presented a browser check, so this probe used the bibliographic record and abstract; full methods and supplements were not reviewed.

The [repository snapshot](https://github.com/lh3/minimap2/tree/3c28777e7e2dcc90f825de1b9f17a89cca7d4452) was pinned, and its README, LICENSE.txt and Makefile were inspected. The actual license text states MIT even though the metadata API returned an unclassified license value. This verifies retrieval and source-to-repository linkage for one public example, not reproduction of the paper's historical code or results. No upstream code was installed, executed or copied into the skill.

## Software checks and limits

The applicable checks are the package/link check, official skill validator and existing isolated installer suite. Their executed results and runtime fingerprints are recorded in [v0.1.4.json](v0.1.4.json).

The new guide has no fixed search-provider dependency or new executable runtime. The live probe does not establish search completeness, broad agent reliability, scientific suitability for a user dataset or native runtime compatibility. The fictional case tests evidence interpretation by manual review; it does not test autonomous search. Earlier independent forward-runs remain scoped to [v0.1.0](v0.1.0.md).
