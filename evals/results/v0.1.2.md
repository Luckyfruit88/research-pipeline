# Version 0.1.2 evaluation record

This patch clarifies method fidelity, preservation of an existing result table, and reuse of intermediates without changing a required joint stage.

## Validation scope

The maintainer reviewed two fabricated scenarios and executed their small numerical examples. This is a manual scenario assessment plus executable illustration, not a blind model evaluation or a performance benchmark. Historical model forward-runs remain documented in [v0.1.0](v0.1.0.md); the preceding scope patch remains in [v0.1.1](v0.1.1.md).

- Method fidelity: the approved current calculation gives 0.4 and 0.6 while retaining every input column and both source row IDs. Agreement with archived values does not establish the missing historical binary version or execution receipt. The current calculation can be delivered with that limitation.
- Cache stages: the full toy batch retains the feature shared by two samples. Applying the same prevalence rule independently to each sample and concatenating results retains none. The shortcut changes the method. Valid split caches remain reusable; the missing split cache and the required joint stage remain outstanding.

No original research was rerun. Installer code and invocation policy are unchanged. The package check, skill validator and existing installer suite are the applicable software checks. Current runtime fingerprints, executed results and bounded upstream review are in [v0.1.2.json](v0.1.2.json).

## Limits

The examples demonstrate the stated arithmetic and aggregation boundary. They do not establish that agents will always follow the revised guidance, prove a historical research run, or validate real cohort results. No token, latency or scientific-performance improvement is claimed.
